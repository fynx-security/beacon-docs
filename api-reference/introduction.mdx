Beacon API is a **FastAPI** service exposing two authenticated surfaces plus public installer routes.

## Base URL

```
https://api.yourdomain.com
```

Local development: `http://localhost:8000`

## OpenAPI

Interactive schema available at:

```
GET /docs      # Swagger UI
GET /redoc     # ReDoc
GET /openapi.json
```

## Authentication summary

| Surface | Auth | Header |
|---------|------|--------|
| Agent routes | Agent JWT (HS256, 5 min) | `Authorization: Bearer <jwt>` |
| Dashboard routes | Clerk JWT | `Authorization: Bearer <jwt>` |
| Dev dashboard | Tenant header | `X-Tenant-ID: org_dev` |
| Internal scheduler | Shared secret | `X-Scheduler-Secret` |
| Register | Install token in body | — |
| Installer | None | — |

## Route prefixes

| Prefix | Tag | Audience |
|--------|-----|----------|
| `/api/agent` | agent | Beacon Host |
| `/api` | dashboard | Beacon Dashboard |
| `/internal` | internal | Digest scheduler |
| `/install.sh`, `/releases` | installer | Bootstrap |

## Response codes

| Code | Meaning |
|------|---------|
| 200 / 201 | Success |
| 204 | Success, no body |
| 401 | Invalid or missing auth |
| 404 | Resource not found |
| 422 | Validation error |
