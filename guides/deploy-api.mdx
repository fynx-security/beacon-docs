## Requirements

- Python 3.12+
- PostgreSQL 15+ (recommended for production)
- Reverse proxy with TLS (nginx, Caddy, cloud load balancer)

## Environment variables

Copy `.env.example` to `.env`:

```bash
DATABASE_URL=postgresql://user:pass@host:5432/beacon
CORS_ORIGINS=https://app.yourdomain.com
DEV_MODE=false

CLERK_SECRET_KEY=sk_live_...
CLERK_JWT_ISSUER=https://your-clerk-domain

AGENT_LATEST_VERSION=0.1.0
AGENT_DOWNLOAD_URL=https://releases.yourdomain.com/beacon-host-agent
AGENT_SHA256=<sha256-of-binary>

HIBP_API_KEY=           # optional paid breach source
REPORT_BRAND_NAME=Beacon
REPORT_BRAND_TAGLINE=Compliance evidence
```

<Warning>
  Set `DEV_MODE=false` in production. Rely on Clerk for tenant isolation.
</Warning>

## Database

```bash
docker compose up -d   # local PostgreSQL
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Tables are created on startup via SQLAlchemy `create_all`. SQLite column migrations run automatically for dev.

## Process manager

Example systemd unit:

```ini
[Unit]
Description=Beacon API
After=network.target

[Service]
User=beacon
WorkingDirectory=/opt/beacon-api
EnvironmentFile=/opt/beacon-api/.env
ExecStart=/opt/beacon-api/.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000
Restart=always

[Install]
WantedBy=multi-user.target
```

Terminate TLS at nginx and proxy to `127.0.0.1:8000`.

## Health checks

| Endpoint | Expected |
|----------|----------|
| `GET /health` | `{"status":"ok"}` |

Use this for load balancer health probes.

## Agent releases

Host `GET /releases/{binary_name}` and `GET /install.sh` from the installer router, or mirror binaries to object storage and set `AGENT_DOWNLOAD_URL`.

## Startup maintenance

On lifespan startup the API:

- Creates missing tables
- Prunes old system log events (>7 days)
- Removes launchd/system noise categories
