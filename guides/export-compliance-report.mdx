title: Export compliance report
description: Generate PDF and JSON audit packs from the dashboard or API.
---

## From the dashboard

1. Open **Compliance**
2. Review overall score and control breakdown
3. Click **Download PDF report** or **JSON audit pack**

Files download with dated filenames:

- `beacon-compliance-summary-2026-06-13.pdf` — executive summary with charts (drill down in the dashboard)
- `beacon-evidence-2026-06-13.json` — full raw audit pack

## From the API

### JSON audit pack

```bash
curl -H "Authorization: Bearer $CLERK_JWT" \
  https://api.yourdomain.com/api/compliance/evidence \
  -o evidence.json
```

Dev mode:

```bash
curl -H "X-Tenant-ID: org_dev" \
  http://localhost:8000/api/compliance/evidence
```

### PDF report

```bash
curl -H "X-Tenant-ID: org_dev" \
  http://localhost:8000/api/compliance/evidence/report \
  -o report.pdf
```

## Customize PDF branding

Set on Beacon API:

```bash
REPORT_BRAND_NAME=Beacon
REPORT_BRAND_TAGLINE=Compliance evidence
DASHBOARD_BASE_URL=https://app.yourdomain.com
```

## Best practices

<Steps>
  <Step title="Export after meaningful change">
    Post-remediation or monthly cadence — not every hour.
  </Step>
  <Step title="Store with timestamp">
    Filename includes date; add ticket or audit reference in your DMS.
  </Step>
  <Step title="Pair PDF with JSON">
    PDF for humans; JSON for verification or custom analytics.
  </Step>
  <Step title="Include scope note">
    Document which agents were in scope for the audit period.
  </Step>
</Steps>
